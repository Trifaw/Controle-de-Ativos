# Gestão de Ativos - Projeto de controle de estoque e logística, desde o banco de dados até a interface.

Projeto dedicado a abranger todas as áreas de logística de uma empresa de pequeno-médio porte. Objetivado a estudar sobre SQL e aguçar a lógica de funcionamento de empresas reais.

Ferramentas Utilizadas: PostgreSQL; BRModelo; VSCode; Complexo Gemini de Ferrementas; Complexo Claude de Ferramentas, Git; Github. 

Como escopo, é pretendido usar o Framework Spring Boot (JAVA). 

Linguagens Usadas: JAVA
Banco de dados: SQL - Postegre
